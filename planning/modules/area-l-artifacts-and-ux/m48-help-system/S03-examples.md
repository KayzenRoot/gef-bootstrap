# M48 S03 — Examples
Status: FROZEN

**EXV48 Executable Example Vault** stores minimal examples as versioned fixtures bound to the same schemas/contracts they document. Examples are safe by default, use synthetic data, declare side effects, and are continuously testable. Destructive/network examples require explicit sandbox labeling and are never auto-run.

Acceptance: fixture/schema binding, synthetic secrets, deterministic expected output, testability, side-effect classification.
