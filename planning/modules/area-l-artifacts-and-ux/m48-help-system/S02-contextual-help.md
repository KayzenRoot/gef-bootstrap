# M48 S02 — Contextual Help
Status: FROZEN

**CHP48 Context Help Projection** maps current canonical state, error code, capability and workflow phase to relevant guidance. Context is explicit input, never inferred from private/ambient data. Guidance distinguishes required next action from optional optimization and never overrides policy or assurance gates.

Acceptance: owner-state fidelity, stale-context marking, privacy-safe context, bounded ranked guidance, no authority escalation.
