# M48 S01 — Help Command
Status: FROZEN

**HCG48 Help Contract Graph** derives command/module help from versioned capability and schema metadata rather than duplicated prose. Help is startup-pure, offline-capable, deterministic and available in human and machine-readable forms. Unknown commands return ranked valid identifiers without executing them.

Acceptance: deterministic output, no side effects/network requirement, schema/version binding, non-interactive parity, bounded suggestions.
