# M59 S01 — Installation Documentation

Status: `FROZEN`
Mechanism: `DSS59 — Documentation Source Synchronizer`

User installation documentation is generated/validated against M49/M51 contracts and tested commands, with separate Windows, Linux and macOS paths. It states prerequisites, user-scoped default, verification, upgrade/uninstall implications and known capability gaps.

Examples use safe copyable commands and never instruct users to bypass signing/quarantine/security controls. Version-specific claims carry source/version markers so stale instructions can be detected.

Acceptance: command snippets are syntax-tested where practical, links/anchors checked, platform differences explicit, no undocumented privilege requirement, and docs drift fails CI rather than silently shipping.
