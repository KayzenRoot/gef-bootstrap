# M40 S02 — Neutral Context Contract
Status: RESERVED
Class: OPTIONAL_ADAPTER

## Invariant
External context can accelerate execution but cannot outrank canonical project sources.

## Mechanisms
- **CCE40 Context Envelope** is bounded and schema-versioned.
- **CCB40 Context Binding** binds a context digest to project, candidate and source hierarchy.
- **CAF40 Authority Firewall** prevents external context from becoming canonical authority.
