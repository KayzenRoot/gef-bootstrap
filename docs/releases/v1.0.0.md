## Highlights
V1.0.0 is the first production-accepted GEF Bootstrap baseline. It packages the governed lifecycle developed across 64 module IDs into a stable source release for both greenfield and brownfield engineering work.

### What ships
- deterministic project/bootstrap governance;
- Work Orders, context locks, preflight and execution contracts;
- preservation-first brownfield adoption;
- checkpoint/resume and project status/progress;
- evidence/proof/delta/assurance/test-impact systems;
- Git/GitHub/CI/release governance;
- security, recovery, integrity and capability detection;
- optional ecosystem adapters plus generic adapter contract;
- telemetry, audit, benchmark and artifact foundations;
- installation/upgrade/compatibility/doctor contracts;
- test, integration, simulation, E2E, performance and security harnesses;
- documentation/runbooks;
- final production acceptance and executor-performance primitives.

## Downloads
The GitHub Release/tag provides GitHub-generated source `.zip` and `.tar.gz` archives. V1.0.0 does not claim a published npm package or standalone binary.

## Known boundaries
- `@gef-bootstrap/cli` remains a private workspace/library surface rather than a published executable.
- GitHub integrations require the relevant external capability/authentication; absence is handled as a capability gap rather than silently bypassed.
- Optional adapters remain optional and are excluded from the release-blocking denominator where defined.

## Upgrade policy
V1 accepted evidence history is immutable-by-policy. Patch maintenance must preserve historical acceptance lineage and use new Work Orders/evidence for material changes.
