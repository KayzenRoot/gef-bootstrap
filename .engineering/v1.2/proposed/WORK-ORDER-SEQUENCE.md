# Proposed V1.2 Work Order Sequence

**State:** `PROPOSED / NOT_CANONICAL`

Each Work Order requires separate admission. Completion of WO-000 does not authorize WO-001 implementation by itself.

## WO-001 — Discovery, Planning Router and Marathon Foundation

**Core:** C01, C02, C04, C10.

Deliver:
- guided discovery contract;
- canonical-answer projection into existing planning/decision/scope authorities;
- owner-confirmed profile routing;
- Marathon durable-wave contract over existing task/context/execution/checkpoint/resume engines;
- accepted metrics for time-to-plan, read/search reuse and execution-wave behavior.

No new parallel planning or execution authority.

## WO-002 — Bug Hunter and Requirement/Invariant Assurance

**Core:** C05.

Deliver:
- requirement/invariant proof model;
- contract/property adapters;
- bounded selective mutation adapter;
- normalization into existing evidence/proof graph;
- false-credit prevention.

## WO-003 — Delta Assurance 2.0, Causal Repair and Flake Control

**Core:** C06.

Deliver:
- explicit invalidation/reuse rules;
- selective-versus-full shadow evidence;
- causal failure fingerprint/repair receipt;
- flake registry/classification;
- zero silent retry-to-green behavior.

If adoption/context behavior changes materially, admit a repeatable brownfield benchmark cohort here.

## WO-004 — Review/Evidence, Engineering Intelligence and Status

**Core:** C07, C08, C09.

Deliver:
- exact-head reviewer packet;
- owner-operated NOT_INDEPENDENT audit semantics;
- comparable engineering-intelligence reports;
- compact pt-BR status composition;
- changed-since-last-state evidence;
- no second status/benchmark authority.

## WO-005 — Web App/API Reference Profile and Visual Experience

**Core/Profile:** C03, C12, D01.

Deliver:
- governed visual-experience contract;
- WEB_APP_API adapter/profile;
- browser/API proof where applicable;
- end-to-end reference journey;
- operations-feedback contract;
- reversible/scoped optional tool installation.

This is the single profile-level core release blocker.

## WO-006 — Release, Reproducibility and Production Acceptance

**Core:** C11 plus integrated C01-C12 closure.

Deliver:
- final exact-head validation;
- V1.1.2 baseline comparison receipts;
- reference profile acceptance;
- cross-platform artifact assurance;
- provenance/integrity/signature/recovery proof;
- operator documentation;
- immutable 1.2.0 release promotion.
