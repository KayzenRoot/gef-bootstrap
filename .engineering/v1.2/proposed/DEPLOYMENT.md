# Proposed V1.2 Deployment Delta

**State:** `PROPOSED / NOT_CANONICAL`

## Core distribution

GEF Bootstrap V1.2 continues the current immutable package/release model.

The release path must preserve or strengthen:
- exact tag/commit binding;
- single exact package artifact;
- cross-platform artifact verification;
- Trusted Publishing/provenance where available in the current release system;
- registry integrity/signature verification;
- clean consumer install smoke;
- recovery/upgrade evidence.

## Reference profile proof

WEB_APP_API may use a controlled reproducible fixture/reference target.

A public production service is not required to prove the GEF core release unless separately admitted.

The reference proof must demonstrate:
- discovery/planning;
- profile selection;
- implementation orchestration evidence;
- validation;
- visual/API proof where applicable;
- package/build/deploy plan;
- rollback/recovery information;
- operations-feedback contract.

## Conditional deployed-app feedback

Operations feedback is opt-in/profile-bound.

No always-on hosted GEF service becomes a universal V1.2 dependency.

## Paid infrastructure

Default is LOCAL_FREE_FIRST.

Any paid CI, cloud preview, commercial scanner or hosted data service requires explicit owner approval before it becomes part of a release gate.

## Web3 EVM pack

The second-priority EVM pack may be developed after/alongside the core only through a separately admitted pack Work Order.

Core V1.2 acceptance does not require mainnet deployment.

Real-asset/mainnet production-ready status invokes the specialist-review gate.
