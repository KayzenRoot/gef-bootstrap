# GEF Bootstrap V1.2 Proposed Source Pack Delta

**Parent:** GBS-V12-WO-000 / Issue #367  
**State:** `PROPOSED / NOT_CANONICAL / NO_IMPLEMENTATION`

This directory is the reviewable V1.2 delta proposal. It does not replace accepted V1.1.2 canonical sources until exact-head owner audit and explicit promotion.

## Release shape

V1.2 is proposed as:

`GEF CORE 1.2 + ONE PROVEN WEB_APP_API REFERENCE PROFILE`

The core release denominator is finite and excludes conditional domain packs by default.

## Universal core

C01-C12 are admitted as one universal capability set, but not as twelve new engines.

The architecture reuses released V1.1.2 authorities and adds only the missing contracts/adapters:
- guided discovery;
- canonical planning composition;
- visual-experience contract;
- Marathon orchestration over existing task/context/execution/checkpoint/resume primitives;
- Bug Hunter assurance adapters;
- Delta Assurance / causal repair / flake controls;
- owner-operated review/evidence packet;
- Engineering Intelligence;
- always-on status composition;
- profile router/install composition;
- release/reproducibility extension;
- operations-feedback contract.

## Reference profile

`WEB_APP_API` is the single release-blocking reference profile.

It must prove the core journey end to end:
discovery -> plan -> execute -> validate -> review -> status -> package/release -> feedback contract.

## Conditional packs

All other D-series profiles are non-release-blocking unless separately admitted.

`WEB3_EVM` is second priority after the core/reference release path, but it remains a conditional pack and receives no core production-ready credit without its own high-assurance evidence.

## Cost posture

`LOCAL_FREE_FIRST`.

No commercial tool, hosted CI expansion or paid scanner becomes mandatory without explicit owner approval.

## High-risk assurance

Qualified specialist review is mandatory before production-ready claims for real-asset mainnet contracts, custody/signing-critical systems, financial value movement/critical ledgers, materially privileged upgrade/admin paths or irreversible high-impact operations.
