## 3. Evidence and mapping rules

- Every case result binds to an exact head SHA and toolchain (`D-0036`).
- Suite results MUST map back to case IDs, not to package coverage (`ARCHITECTURE.md` A10).
- A schema/contract introduced by a Work Order MUST ship with the tests that prove it (this matrix plus per-WO tests).
- An unrun suite is reported as `NOT_RUN`; it is never inferred as passing.
- WO-010 promotion requires the full matrix green at the exact promoted head, on all three platforms, for every ✓ column.
